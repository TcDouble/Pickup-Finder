# PickupFinder for iOS

The iOS app runs the website's own pages inside a native iOS shell built with
[Capacitor](https://capacitorjs.com/), so it has the same features as the
website and uses the same Firebase project and accounts (issue #16). On top of
the website it adds iOS-only touches:

- **Share a game:** every game card gets a Share button that opens the iOS
  share sheet, so players can send a game to friends in Messages, Mail or AirDrop.
- A home-screen icon and launch screen in the site's colors, and native
  permission prompts for location (games near you) and photos (profile picture).

## What's in this folder

| Path | What it is |
| --- | --- |
| `scripts/build-web.js` | Copies the website's pages into `www/`, adds `native/app-shell.js` to each page, and starts Firebase Auth without its popup sign-in helper, which never loads inside the app and would leave every page blank. Never changes the website's files. |
| `native/app-shell.js` | The iOS-only extras (the Share button). Does nothing in a normal browser. |
| `ios/` | The Xcode project (generated by Capacitor, then edited: `App/App/Info.plist`, icons). |
| `scripts/make-icons.swift` | Draws the app icon and launch screen. |
| `test/` | Unit tests for the two scripts (`npm test`). |

`www/` and `node_modules/` are build output and are not committed.

## Run it in the iOS Simulator

You need a Mac with Xcode (and its iOS Simulator runtime) and Node.js 20 or later.

```bash
cd ProjectSourceCode/mobile
npm install
MAPS_API_KEY=<your Google Maps key> npm run sync   # copy the pages into the Xcode project
npm run open                                      # opens Xcode
```

In Xcode, pick an iPhone simulator and press Run (⌘R). Without `MAPS_API_KEY`
(or a `login-and-registration/maps-config.local.js`) the app still works but
the map stays empty.

Run `npm run sync` again after changing any page of the website, so the app
gets the change.

## Run it on your own iPhone

1. Connect the iPhone, open the project with `npm run open`, and choose the
   iPhone as the run destination.
2. In the **App** target's **Signing & Capabilities**, choose your Apple ID's
   team (a free Personal Team works) and, if Xcode asks, a unique bundle
   identifier.
3. Press Run. The first time, trust the developer on the iPhone in
   Settings > General > VPN & Device Management.

Apps signed with a free Personal Team stop opening after 7 days; run again
from Xcode to renew. Putting the app on TestFlight or the App Store, and real
push notifications through Apple's servers, need a paid Apple Developer
Program membership.
